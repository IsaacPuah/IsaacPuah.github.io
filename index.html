01 About

I like making things that think, move, and sometimes fly. My background sits between embedded systems and full-stack software — flight controllers on one screen, React components on the other.

Lately I've been drawn to the places where code meets physical systems: autonomous navigation, real-time telemetry, and the small engineering decisions that make a machine feel deliberate rather than lucky.

Curious about PID loops, clean type, and the question of how much software can be honestly described as “simple.”
